Toda a composição visual da locomotiva a vapor foi modelada utilizando primitivas analíticas puras do subsistema vetorial do WPF em `Controls/LocomotivaControl.xaml`. O cenário ferroviário, a iluminação e o leito dos trilhos encontram-se em `MainWindow.xaml`.

A modelagem dispensa qualquer uso de imagens rasterizadas (bitmaps), garantindo renderização nítida em qualquer resolução e fator de escala DPI.

## 2. Tangência Geométrica Roda-Trilho

Para garantir que a composição repouse perfeitamente sobre a via férrea sem flutuar ou penetrar no lastro, as cotas foram sincronizadas analiticamente:

$$
Y_{\text{contato}} = Y_{\text{origem\_loco}} + Y_{\text{centro\_eixo}} + R_{\text{roda}}
$$

Substituindo os valores numéricos definidos no modelo:
- Posição vertical da locomotiva na janela: $Y_{\text{origem\_loco}} = 155.0\text{ px}$
- Altura do centro dos eixos no Canvas da máquina: $Y_{\text{centro\_eixo}} = 210.0\text{ px}$
- Raio primitivo externo da roda: $R_{\text{roda}} = 40.0\text{ px}$

$$
Y_{\text{contato}} = 155.0 + 210.0 + 40.0 = \mathbf{405.0\text{ px}}
$$

A face superior do boleto do trilho em `MainWindow.xaml` foi posicionada exatamente em $Y = 405.0\text{ px}$, atingindo uma linha de tangência sem descontinuidade visual.

## 3. Anatomia da Locomotiva 0-4-0T

A composição reproduz uma clássica locomotiva industrial do tipo **0-4-0T (Tank Engine)**:
- **0 rodeiros-guia dianteiros**: Foco em esforço de tração e manobra.
- **4 rodas motrizes acopladas**: Distribuídas em dois eixos paralelos sustentando a totalidade da massa aderente.
- **T (Tanque Integrado)**: Tanques de reserva de água e carvão fixados diretamente sobre o chassi e laterais da caldeira.

```
                                [DOMO]  [SINO]     [CHAMINÉ]
                                 (  )     ||          ||
         [TETO CABINE]        +-------+-------+----+----+
        /=============\       |       |       |    |    |
====|                 |=======|        CALDEIRA    |    |===[>] [FAROL]
    |     CABINE      |       |                    |    |
    |                 |       +--------------------+----+
    |  [PORTA]  [JAN] |       |   TANQUE LATERAL   |      [CILINDRO]
----+-----------------+-------+--------------------+      [======]
|=====[RODA 1]=====[BIELA ACOPLAMENTO]=====[RODA 2]=====[CRUZETA] \> [PILOT]
==================================================================== [TRILHO]
```
