## 2. Fatores Técnicos Determinantes para o Score A

1. **Separação Rígida de Responsabilidades**: A camada cinemática (`LocomotivaKinematics.cs`) é desprovida de chamadas à API de UI do WPF, o que reduz a complexidade ciclomática média a níveis inferiores a 5.
2. **Estruturas de Dados por Valor**: O DTO de quadro foi modelado como `readonly record struct LocomotivaFrameState`, impedindo alocações dinâmicas no heap e garantindo imutabilidade thread-safe.
3. **Padrão de Templates Reutilizáveis**: O isolamento dos raios e aro das rodas no `ControlTemplate` de `LocomotivaResources.xaml` eliminou a duplicação de marcação XAML entre os rodeiros dianteiro e traseiro.
4. **Convenção Semântica e Formatação Consistente**: Ausência de warnings do compilador Roslyn e adesão integral às diretrizes do `.editorconfig`.

## 3. Configuração do Scanner (`sonar-project.properties`)

```properties
# Identificação do Projeto
sonar.projectKey=PI_T1
sonar.projectName=PI_T1 - Locomotiva a Vapor 2D (WPF)
sonar.projectVersion=1.0.0

# Codificação
sonar.sourceEncoding=UTF-8

# Escopo de Inclusão
sonar.sources=.
sonar.inclusions=**/*.cs,**/*.xaml

# Exclusões de Build e Metadados
sonar.exclusions=bin/**,obj/**,.gemini/**,.agents/**,.vscode/**,Slide/**,Trabalho/**,wiki/**,docs/**
```
