A **Locomotiva a Vapor 2D** é um projeto de computação visual e engenharia de software desenvolvido para a disciplina de **Processamento de Imagens (Trabalho C1)**, implementado na linguagem **C# (.NET 10)** sobre o subsistema vetorial acelerado por hardware do **Windows Presentation Foundation (WPF)**.

O trabalho tem como objetivo central aplicar transformações afins 2D (translação, rotação, escala e espelhamento), composição gráfica modular via matrizes de renderização, desacoplamento em coordenadas canônicas $(0,0)$ e modelagem matemática analítica em tempo real de mecanismos acoplados de quatro barras e biela-manivela.

---

## Demonstração Visual do Sistema

O percurso ferroviário é modelado em regime contínuo de **vai-e-volta (Ping-Pong)** nos limites visíveis da janela. A composição desacelera suavemente ao se aproximar de cada terminal, efetua uma pausa técnica de manobra, inverte o sentido de marcha com espelhamento simétrico e acelera suavemente em direção oposta:

## Requisitos de Ambiente e Execução Local

### Pré-requisitos de Sistema

- **Sistema Operacional**: Microsoft Windows 10 ou Windows 11 (requerido para o subsistema nativo WPF e aceleração DirectX).
- **Runtime e SDK**: [.NET 10 SDK](https://dotnet.microsoft.com/download) ou superior.
- **Ferramenta de Automação (Opcional)**: FFmpeg para regeneração de vídeos de demonstração via script PowerShell.

### Instruções de Compilação e Execução

Para compilar e executar o projeto diretamente via terminal PowerShell:

```powershell
# 1. Navegar até o diretório raiz do projeto
cd d:\ProcessamentoDeImagens\PI_T1

# 2. Restaurar dependências e compilar a solução em modo Release
dotnet build PI_T1.sln -c Release

# 3. Executar o aplicativo WPF interativo
dotnet run
```

### Comandos para Teste Headless e Captura Determinística

A aplicação implementa parâmetros de linha de comando para auditoria automatizada e validação visual de quadros:

```powershell
# Captura de quadro determinístico no instante t = 3.5 segundos
dotnet run -- --screenshot 3.5 frame_check.png

# Gravação de quadros brutos em pasta para análise visual (15 segundos a 20 FPS)
dotnet run -- --record-frames 15.0 20 frames_dir
```
